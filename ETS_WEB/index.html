Penjelasan Evaluasi Tengah Semester (ETS)

Soal Evaluasi Tengah Semester (ETS) :

Soal 1

Jelaskan deskripsi dan ruang lingkup fitur aplikasi Desktop Rich UI yang dibuat.

Jawaban Soal 1:

A. Deskripsi Aplikasi Desktop Rich UI

Aplikasi yang dibangun bernama Bank Soal .NET, yaitu sebuah sistem pembelajaran, katalog bank soal kurikulum, modul studi kasus, dan evaluasi ujian interaktif berbasis Desktop Rich UI yang dikembangkan menggunakan framework Windows Presentation Foundation (WPF) pada ekosistem .NET 8 (C# 12).

Predikat Rich UI (Rich User Interface) pada aplikasi ini diwujudkan melalui:

  • Tema Visual Modern (Dark Slate Theme): Antarmuka bertema gelap elegan (basis warna Slate #0F172A dan #1E293B dengan aksen ungu #7C3AED) yang dirancang menggunakan Material Design in XAML Toolkit untuk meminimalkan kelelahan mata saat belajar dalam durasi lama.
  • Tata Letak Kartu Interaktif & Komponen Dinamis: Menggunakan kartu elevasi, lencana peran (*Role Badges*), animasi hover, tombol radio tab beranimasi, serta indikator visual warna real-time untuk status kelulusan (lencana hijau/merah).
  • Pengalaman Responsif Tanpa Hambatan (Zero-Lag UI): Seluruh operasi I/O basis data dan rendering berkas berjalan secara asinkron (async/await), sehingga UI desktop tetap mulus dan responsif tanpa fenomena freezing.

B. Ruang Lingkup Fitur (Scope of Features)

1. Autentikasi Terpadu & RBAC

Satu pintu masuk (Unified Login) untuk Mahasiswa dan Dosen/Admin dengan deteksi peran otomatis, fitur pendaftaran akun baru dengan validasi data, serta tombol Quick-Fill Demo instan.

2. Manajemen Kurikulum & Materi

CRUD Master Data Mata Kuliah (Kode, Nama, SKS, Semester, Ikon Material, dan Warna) serta pengelolaan Materi Pembelajaran per pertemuan terelasi secara relasional.

3. Manajemen Bank Soal (PG & Essay)

Pengelolaan bank soal fleksibel mendukung tipe Pilihan Ganda (4 opsi jawaban) dan Essay (pembahasan detail serta kata kunci evaluasi otomatis).

4. Katalog Bank Soal & Kunci Interaktif

Penyajian kumpulan soal untuk studi mandiri dengan filter multi-kriteria dan fitur sakelar Kunci Jawaban: ON / OFF yang langsung menyorot opsi benar dan kunci resmi.

5. Embedded PDF Reader (WebView2)

Pembaca dokumen PDF terintegrasi penuh di dalam window aplikasi tanpa browser luar untuk membaca kisi-kisi dan silabus, lengkap dengan fitur upload berkas PDF.

6. Mode Belajar & Scoring (Auto-Grading)

Mahasiswa dapat membaca materi secara mandiri dan mengerjakan simulasi ujian dengan timer serta mesin penilaian otomatis (auto-grading) langsung.

7. Rekapitulasi & Riwayat Nilai

Pencatatan riwayat skor mandiri bagi mahasiswa serta halaman rekapitulasi nilai seluruh mahasiswa bagi Dosen/Admin untuk monitoring performa akademik.

8. Basis Data Relasional Serverless

Menggunakan SQLite via Entity Framework Core 8 yang tertanam langsung (in-process) dengan skema relasional tabel terstruktur tanpa instalasi server SQL eksternal.

Soal 2

Apa latar belakang dan Manfaat aplikasi tersebut di buat.

Jawaban Soal 2:

A. Latar Belakang Pengembangan Aplikasi

Pengembangan aplikasi Bank Soal .NET dilatarbelakangi oleh sejumlah tantangan nyata dalam proses pembelajaran mata kuliah Pemrograman Berbasis Kerangka Kerja (PBKK):

  1. Kebutuhan Pemahaman Mendalam Konsep Framework .NET: Materi PBKK mencakup spektrum konsep teoretis dan praktis yang luas (seperti Common Language Runtime, arsitektur WPF, XAML, MVVM, ADO.NET, dan ORM Entity Framework). Mahasiswa memerlukan sarana evaluasi mandiri yang terstruktur per bab/pertemuan agar pemahaman konsep dapat teruji secara berkala.
  2. Fragmentasi Bahan Ajar dan Dokumen Kisi-Kisi Soal: Selama ini bahan kuliah, lembar kisi-kisi ujian, dan bank soal latihan sering kali tersebar di berbagai tautan Google Drive, grup perpesanan, atau berkas PDF lokal yang tercecer. Mahasiswa kesulitan mencari referensi latihan yang komprehensif dalam satu lingkungan terpadu.
  3. Keterbatasan Aplikasi Desktop Konvensional: Banyak aplikasi evaluasi desktop lama masih dibangun menggunakan antarmuka Windows Forms klasik yang kaku, memiliki visual monokromatik yang membosankan, serta tidak mampu merender dokumen multimedia atau PDF secara native tanpa membuka aplikasi pihak ketiga.
  4. Implementasi Riil Prinsip Desktop Rich UI pada Evaluasi Tengah Semester (ETS): Sebagai pembuktian penguasaan kompetensi PBKK, aplikasi ini dikembangkan untuk mendemonstrasikan integrasi kerangka kerja modern: arsitektur WPF dengan XAML responsif, styling Material Design, efisiensi SQLite serverless, dan integrasi komponen embedded Microsoft Edge WebView2.

B. Manfaat Aplikasi

Penerima Manfaat Manfaat yang Diperoleh
Bagi Mahasiswa
  • Akses Belajar Terpusat: Mempelajari materi perkuliahan, bank soal resmi, dan membaca silabus/kisi-kisi PDF dalam satu aplikasi tanpa perlu berganti-ganti jendela software.
  • Umpan Balik Instan (Immediate Feedback): Mengetahui hasil evaluasi secara langsung melalui sistem penilaian otomatis (auto-grading) dan pembahasan kunci jawaban.
  • Pengalaman Belajar Nyaman: Antarmuka Rich UI bertema gelap (Dark Theme) yang nyaman di mata, responsif, dan mudah dinavigasikan.
  • Pemantauan Progres Mandiri: Riwayat skor ujian tersimpan rapi sehingga mahasiswa dapat mengevaluasi topik-topik perkuliahan yang masih perlu diperdalam.
Bagi Dosen / Pengajar
  • Sentralisasi Manajemen Kurikulum: Memudahkan pengelolaan mata kuliah, pengelompokan materi per pertemuan, serta penambahan butir soal baru (PG dan Essay).
  • Penyebaran Modul PDF Terintegrasi: Dosen dapat langsung mengunggah berkas PDF kisi-kisi atau lembar studi kasus ke sistem untuk dibaca oleh seluruh mahasiswa.
  • Transparansi Monitoring Mahasiswa: Rekapitulasi nilai dan metrik aktivitas mahasiswa dapat dipantau langsung dari dashboard administratif.
Bagi Praktik Akademik PBKK
  • Menjadi proyek percontohan (reference project) implementasi arsitektur perangkat lunak desktop tingkat lanjut yang menerapkan pemisahan tugas (Separation of Concerns) antara UI XAML, model data C#, dan persistensi database EF Core.

Saat proses login berhasil, sistem secara otomatis membaca atribut Role dari akun tersebut dan mengarahkan ke antarmuka yang sesuai. Terdapat pula tombol Quick-Fill Demo untuk mempermudah pengujian dosen penguji.

Implementasi Logika Login Asinkron (C#) :

// Method autentikasi pada DatabaseService.cs
public async Task<User?> LoginAsync(string username, string password)
{
    // Verifikasi keberadaan akun berdasarkan username dan password
    var user = await _db.Users.FirstOrDefaultAsync(u => 
        u.Username.ToLower() == username.ToLower() && 
        u.Password == password);

    return user;
}

// Handler tombol masuk pada LoginWindow.xaml.cs
private async void BtnLogin_Click(object sender, RoutedEventArgs e)
{
    string username = TxtUsername.Text.Trim();
    string password = TxtPassword.Password;

    var user = await _db.LoginAsync(username, password);
    if (user == null)
    {
        TxtError.Text = "Username atau password salah.";
        TxtError.Visibility = Visibility.Visible;
        return;
    }

    // Navigasi ke jendela kerja utama berdasarkan Role
    var shell = new MainShell(user, _db);
    shell.Show();
    this.Close();
}

Proses pengecekan dilakukan secara asinkron (async/await) agar UI tidak mengalami freeze saat mengakses basis data SQLite.

// Penyaringan soal berdasarkan Mata Kuliah, Topik, Tipe, dan Keyword
private void ApplyFilter()
{
    var query = _allSoalList.AsEnumerable();

    if (_selectedMatkulId > 0)
        query = query.Where(s => s.Materi?.MataKuliahId == _selectedMatkulId);

    if (_selectedMateriId > 0)
        query = query.Where(s => s.MateriId == _selectedMateriId);

    if (!string.IsNullOrWhiteSpace(searchKeyword))
        query = query.Where(s => s.Pertanyaan.Contains(searchKeyword, StringComparison.OrdinalIgnoreCase));

    IcSoalList.ItemsSource = query.ToList();
}

// Inisialisasi WebView2 kontrol di DokumenPdfView.xaml.cs
private async Task RenderPdfDocument(string filePath)
{
    if (!File.Exists(filePath)) return;

    // Menunggu CoreWebView2 runtime siap
    await PdfWebView.EnsureCoreWebView2Async();
    
    // Membuka URI berkas lokal langsung ke engine Chromium WebView2
    var fileUri = new Uri(filePath).AbsoluteUri;
    PdfWebView.CoreWebView2.Navigate(fileUri);
}

Mahasiswa disuguhkan dua metode belajar mandiri:

  • Mode Belajar: Mahasiswa membaca rangkuman teori per pertemuan beserta contoh sintaks sebelum memulai ujian.
  • Mode Scoring (Ujian): Mahasiswa mengerjakan paket kuis interaktif dengan umpan balik cepat dan auto-grading.
Gambar 9: Mode Belajar Mahasiswa untuk Mempelajari Silabus dan Modul Pertemuan

Algoritma Auto-Grading & Scoring (C#) :

// Perhitungan nilai pada ModeScoringView.xaml.cs
private async void BtnSubmitUjian_Click(object sender, RoutedEventArgs e)
{
    int totalSoal = _listSoal.Count;
    int benarPg = 0;
    int totalBobotEssay = 0;

    foreach (var soal in _listSoal)
    {
        if (soal.TipeSoal == "PG")
        {
            if (_jawabanMahasiswa[soal.Id] == soal.KunciJawaban)
                benarPg++;
        }
        else if (soal.TipeSoal == "Essay")
        {
            // Pencocokan kata kunci esensial jawaban mahasiswa
            string text = _jawabanEssay[soal.Id].ToLower();
            string[] keywords = soal.KunciJawaban.ToLower().Split(' ');
            int matches = keywords.Count(k => text.Contains(k));
            if (matches >= (keywords.Length / 2))
                totalBobotEssay += 1;
        }
    }

    double skorAkhir = ((double)(benarPg + totalBobotEssay) / totalSoal) * 100.0;
    
    // Simpan ke riwayat hasil ujian SQLite
    var hasil = new HasilUjian
    {
        UserId = _currentUser.Id,
        MateriId = _selectedMateriId,
        Nilai = Math.Round(skorAkhir, 2),
        TanggalUjian = DateTime.Now
    };
    await _db.SimpanHasilUjianAsync(hasil);
    MessageBox.Show($"Ujian Selesai! Skor Anda: {hasil.Nilai}", "Hasil Evaluasi");
}
