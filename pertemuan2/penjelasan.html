Penjelasan Tugas 1

Soal :

Membuat aplikasi desktop sederhana sistem pendataan mahasiswa, dengan fitur-fitur :

  • Menambah data mahasiswa.
  • Mencari data mahasiswa berdasarkan NIM atau nama.
  • Menghapus data mahasiswa.
  • Menampilkan daftar semua mahasiswa.
  • keluar dari aplikasi.

Jawaban :

Disini saya menggunakan framework .NET. bahasa yang digunakan yaitu bahasa C# sebagai logika dan bahasa XAML untuk tampilan.


        <StackPanel HorizontalAlignment="Center" VerticalAlignment="Center">
        
        <TextBlock Text="Selamat Datang di Aplikasi Desktop" FontSize="24" FontWeight="Bold" Margin="0,0,0,20"/>
        <Button Content="Masuk" Width="150" Height="50" Click="masuk_click"/>
        
        </StackPanel>

Logika Menu Dashboard (C#)

Pada bagian Dashboard, aplikasi hanya berisi tombol menu navigasi. Setiap kali tombol ditekan, ia akan memanggil halaman (Window) baru yang dikhususkan untuk satu fungsi (Tambah, Cari, Hapus, Lihat). Berikut adalah penjelasan logika C# pada masing-masing tombol:

1. Tombol Tambah Data


    private void tambah_data_click(object sender, RoutedEventArgs e)
    {
        TambahData windowTambah = new TambahData();
        windowTambah.ShowDialog();
    }

Metode ini membuat instance dari class TambahData (yang merupakan halaman window baru) lalu menampilkannya menggunakan ShowDialog(). Penggunaan ShowDialog() bertujuan agar pengguna harus menyelesaikan aktivitas di jendela tersebut sebelum bisa kembali menekan menu di Dashboard.

2. Tombol Cari Data


    private void cari_data_click(object sender, RoutedEventArgs e)
    {
        CariData windowCari = new CariData();
        windowCari.ShowDialog();
    }

Fungsi ini membuka jendela CariData tempat pengguna bisa memasukkan NIM untuk mencari data yang ada di DataStore.

3. Tombol Hapus Data


    private void hapus_data_click(object sender, RoutedEventArgs e)
    {
        HapusData windowHapus = new HapusData();
        windowHapus.ShowDialog();
    }

Fungsi ini akan membuka jendela HapusData untuk memproses penghapusan data dari list mahasiswa.

4. Tombol Lihat Data


    private void lihat_data_click(object sender, RoutedEventArgs e)
    {
        LihatData windowLihat = new LihatData();
        windowLihat.ShowDialog();
    }

Tombol ini memanggil jendela LihatData yang berisi sebuah tabel (DataGrid) yang terhubung ke data mahasiswa untuk menampilkan isi daftarnya.

5. Tombol Keluar


    private void keluar_click(object sender, RoutedEventArgs e)
    {
        this.Close();
    }

Perintah this.Close() akan menutup Window Dashboard, yang secara efektif akan mengakhiri berjalannya aplikasi karena merupakan jendela utama.
