Soal :

Membuat aplikasi desktop Student Registration App menggunakan Windows Presentation Foundation (WPF) dengan fitur CRUD in-memory (Simpan, Edit, Hapus, Cari, dan Reset).

Jawaban :

github code

Aplikasi ini dibuat menggunakan framework .NET dengan pendekatan arsitektur WPF modern. File XAML digunakan secara eksklusif untuk menyusun User Interface (UI) yang kaya dan menarik, sementara file C# (.xaml.cs) berperan di belakang layar sebagai logika interaksi dan validasi. Aplikasi ini sudah dikembangkan hingga memenuhi tantangan "Level 2" yang mencakup komponen yang lebih bervariasi, pencarian data, serta sistem update.

Kode XAML di atas mendemonstrasikan bagaimana WPF mengikat elemen UI. Kami menggunakan DatePicker untuk kemudahan entri tanggal lahir, RadioButton untuk jenis kelamin, dan DataGrid untuk menampilkan tabel data mahasiswa yang secara otomatis akan tersinkronisasi (Data Binding).

2. Data Binding & ObservableCollection


private ObservableCollection<Student> _mahasiswaList;

public MainWindow()
{
    InitializeComponent();
    _mahasiswaList = new ObservableCollection<Student>();
    dgMahasiswa.ItemsSource = _mahasiswaList;
}

Kami menggunakan ObservableCollection<Student> untuk menyimpan data secara in-memory. Keunggulan koleksi ini di WPF adalah jika terjadi perubahan (penambahan atau penghapusan elemen), maka tabel DataGrid pada tampilan akan otomatis diperbarui tanpa perlu dipanggil secara manual.

3. Validasi & Proses Simpan


private void BtnSimpan_Click(object sender, RoutedEventArgs e)
{
    if (!ValidateInput()) return;

    var student = new Student
    {
        Nim = txtNim.Text,
        Nama = txtNama.Text,
        Prodi = (cmbProdi.SelectedItem as ComboBoxItem)?.Content.ToString(),
        JenisKelamin = rbLaki.IsChecked == true ? "Laki-laki" : "Perempuan",
        TanggalLahir = dpTanggalLahir.SelectedDate,
        Alamat = txtAlamat.Text,
        NoTelepon = txtNoTelepon.Text
    };

    _mahasiswaList.Add(student);
    MessageBox.Show("Data mahasiswa berhasil disimpan!");
    ResetForm();
    UpdateJumlahMahasiswa();
}

Sebelum menyimpan, aplikasi akan memanggil method ValidateInput(). Jika input kosong atau tidak lengkap, form akan menampilkan pesan Warning. Jika valid, instance Student baru akan dibuat dan ditambahkan ke _mahasiswaList.

4. Konfirmasi Penghapusan


private void BtnDelete_Click(object sender, RoutedEventArgs e)
{
    var btn = sender as Button;
    var student = btn?.DataContext as Student;

    if (student != null)
    {
        var result = MessageBox.Show($"Apakah Anda yakin ingin menghapus {student.Nama}?", 
            "Konfirmasi", MessageBoxButton.YesNo, MessageBoxImage.Question);
        
        if (result == MessageBoxResult.Yes)
        {
            _mahasiswaList.Remove(student);
            UpdateJumlahMahasiswa();
        }
    }
}

Fitur hapus diimplementasikan melalui tombol di dalam setiap baris tabel. Tombol tersebut membawa DataContext berupa objek Student spesifik di baris tersebut. Kami menggunakan konfirmasi MessageBox.YesNo untuk mencegah penghapusan data secara tidak sengaja.

5. Fitur Pencarian (Search)


private void BtnSearch_Click(object sender, RoutedEventArgs e)
{
    string keyword = txtSearch.Text.ToLower();
    
    if (string.IsNullOrWhiteSpace(keyword))
    {
        dgMahasiswa.ItemsSource = _mahasiswaList; // Kembali tampilkan semua
    }
    else
    {
        var filteredList = _mahasiswaList.Where(s => 
            (s.Nim != null && s.Nim.ToLower().Contains(keyword)) || 
            (s.Nama != null && s.Nama.ToLower().Contains(keyword))
        ).ToList();
        
        dgMahasiswa.ItemsSource = filteredList; // Tampilkan hasil filter
    }
}

Fungsi ini memanfaatkan LINQ di C# untuk memfilter daftar mahasiswa berdasarkan kata kunci yang diinput. Jika keyword cocok dengan sebagian NIM atau Nama, data tersebut akan ditampilkan ke tabel tanpa mengubah daftar asli yang disimpan di memori.
