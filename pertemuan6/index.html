Penjelasan Kueri SQL

1. Memilih Database
USE StudentRegistrationDB;
GO
Kueri ini digunakan untuk mengatur konteks database yang aktif. Semua perintah selanjutnya akan dieksekusi di dalam database StudentRegistrationDB. GO adalah penanda akhir *batch* instruksi untuk SQL Server.
2. Mengisi Data Program Studi
INSERT INTO Programs (ProgramCode, ProgramName)
VALUES
('TI', 'Teknik Informatika'),
('SI', 'Sistem Informasi'),
('MNJ', 'Manajemen'),
('TE', 'Teknik Elektro'),
('DKV', 'Desain Komunikasi Visual');
GO
Menyisipkan beberapa data *dummy* (contoh) ke dalam tabel Programs. Kita mengisi kode program (singkatan jurusan) dan nama program studi secara sekaligus (Bulk Insert).
3. Mengisi Data Mahasiswa
INSERT INTO Students (NIM, Name, ProgramId, BirthDate, Address, PhoneNumber)
VALUES
('20241001', 'Ahmad Rizki', 1, '2005-03-12', 'Jl. Merdeka No. 123, Surabaya', '081234567890'),
('20241002', 'Siti Aisyah', 2, '2005-07-21', 'Jl. Diponegoro No. 45, Surabaya', '082233445566'),
...
GO
Menyisipkan data mahasiswa ke dalam tabel Students. Terdapat relasi *Foreign Key* pada kolom ProgramId yang merujuk ke tabel Programs. Data ini mencakup NIM, Nama, Tanggal Lahir, Alamat, dan Nomor Telepon.
4. Menampilkan Semua Data
SELECT * FROM Programs;
SELECT * FROM Students;
Menampilkan seluruh kolom dan baris yang ada di dalam tabel Programs dan Students secara terpisah.
5. Menampilkan Data dengan INNER JOIN
SELECT
s.StudentId, s.NIM, s.Name, p.ProgramCode, p.ProgramName, s.BirthDate, s.PhoneNumber 
FROM Students s 
INNER JOIN Programs p ON s.ProgramId = p.ProgramId;
Ini adalah kueri untuk menggabungkan tabel Students (s) dengan Programs (p) berdasarkan kolom relasinya (ProgramId). Tujuannya agar kita dapat melihat nama jurusan mahasiswa secara langsung alih-alih hanya melihat angka ID-nya.
6. Uji Coba Kueri Error & Validasi Data
INSERT INTO Students (NIM, Name, ProgramId) VALUES ('20231099', 'Test Student', 99);
INSERT INTO Students (NIM, Name, ProgramId) VALUES ('20231001', 'Mahasiswa Duplikat', 1);
Kueri pertama akan mengalami *error* jika terdapat konstrain FOREIGN KEY yang ketat, karena ProgramId = 99 tidak ada di tabel Programs. Kueri kedua menginput data dengan ProgramId = 1 yang ada, sehingga valid.
7. Mengurutkan Data berdasarkan Nama
SELECT
s.NIM, s.Name, p.ProgramName, s.BirthDate, s.PhoneNumber 
FROM Students s 
INNER JOIN Programs p ON s.ProgramId = p.ProgramId 
ORDER BY s.Name;
Sama seperti kueri JOIN sebelumnya, namun dengan tambahan klausa ORDER BY s.Name. Kueri ini akan menampilkan hasil secara urut abjad berdasarkan kolom Nama Mahasiswa dari A hingga Z.
