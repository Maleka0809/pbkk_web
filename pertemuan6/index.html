Penjelasan Tugas 5

Soal :

Membuat aplikasi desktop Student Registration App menggunakan Windows Presentation Foundation (WPF) yang terhubung ke database SQL Server menggunakan ADO.NET dengan fitur CRUD lengkap.

Jawaban :

github code

Aplikasi ini dibuat menggunakan framework .NET. Bahasa yang digunakan yaitu bahasa C# sebagai logika (termasuk akses database via Repositori) dan bahasa XAML untuk antarmuka pengguna, sedangkan penyimpanan data langsung menggunakan SQL Server melalui ADO.NET.

Logika Utama Aplikasi (SQL & C#)

Berikut adalah penjelasan kueri SQL dan implementasi C# yang berjalan di balik layar:

1. Kueri Persiapan Database & Tabel (SQL)


USE StudentRegistrationDB;
GO

INSERT INTO Programs (ProgramCode, ProgramName)
VALUES
('TI', 'Teknik Informatika'),
('SI', 'Sistem Informasi'),
('MNJ', 'Manajemen'),
('TE', 'Teknik Elektro'),
('DKV', 'Desain Komunikasi Visual');
GO

Kueri ini digunakan untuk memilih database yang aktif dan mengisi data awal (dummy) ke tabel Programs secara sekaligus (Bulk Insert).

2. Mengisi Data Mahasiswa & Relasi (SQL)


INSERT INTO Students (NIM, Name, ProgramId, BirthDate, Address, PhoneNumber)
VALUES
('20241001', 'Ahmad Rizki', 1, '2005-03-12', 'Jl. Merdeka No. 123, Surabaya', '081234567890'),
('20241002', 'Siti Aisyah', 2, '2005-07-21', 'Jl. Diponegoro No. 45, Surabaya', '082233445566'),
...

Menyisipkan data mahasiswa ke dalam tabel Students. Terdapat relasi Foreign Key pada kolom ProgramId yang merujuk ke tabel Programs.

3. Pengambilan Data dengan INNER JOIN (SQL)


SELECT
s.StudentId, s.NIM, s.Name, p.ProgramCode, p.ProgramName, s.BirthDate, s.PhoneNumber 
FROM Students s 
INNER JOIN Programs p ON s.ProgramId = p.ProgramId 
ORDER BY s.Name;

Kueri ini digunakan untuk menggabungkan tabel Students dengan Programs berdasarkan ProgramId, agar kita dapat menampilkan nama jurusan secara langsung. Hasilnya kemudian diurutkan berdasarkan abjad dengan ORDER BY.

4. Menampilkan Data di Aplikasi WPF

Aplikasi WPF memanggil metode dari StudentRepository yang mengeksekusi kueri SELECT di atas melalui SqlConnection dan SqlCommand. Hasilnya kemudian dimasukkan ke dalam DataGrid.

5. Implementasi Fitur CRUD

Fitur CRUD (Tambah, Edit, Hapus) difasilitasi oleh form terpisah. Saat tombol disubmit, aplikasi akan memanggil method repository yang secara otomatis mengeksekusi parameterized query (INSERT, UPDATE, atau DELETE) secara aman untuk mencegah SQL Injection.
