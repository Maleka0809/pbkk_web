Pertemuan 5

Dokumentasi Pembuatan Dashboard UI menggunakan WPF & C#

Tentang Proyek

Pada pertemuan 5 ini, kita telah membangun sebuah aplikasi desktop Windows Presentation Foundation (WPF) berbasis .NET. Fokus utama dari proyek ini adalah merancang antarmuka pengguna (UI) modern yang berupa sebuah Dashboard. Untuk mencapai desain yang bersih, minimalis, dan kekinian, proyek ini mengintegrasikan pustaka desain MaterialDesignThemes.

Struktur Kode Utama

Terdapat dua file utama yang kita ubah/konfigurasi pada pembuatan Dashboard UI ini:

1. App.xaml

File ini bertindak sebagai pusat sumber daya aplikasi. Di sini kita mendeklarasikan penggunaan Material Design sehingga dapat diakses oleh semua jendela/komponen aplikasi. Kita menggunakan BundledTheme dengan tema dasar terang (Light) dan warna aksen DeepPurple & Lime.

2. MainWindow.xaml

File ini berisi markup XAML utama yang mendefinisikan layout dan struktur Dashboard. Layout ini dibagi menggunakan sistem Grid dengan dua kolom utama:

  • Kolom 1 (Sidebar): Berisi menu navigasi vertikal (Home, Analytics, Customers, Settings). Kita menghilangkan ikon Dashboard utama sesuai revisi terakhir agar terlihat lebih rapi.
  • Kolom 2 (Main Content): Area kerja utama yang berisi Header (notifikasi & foto profil), Kartu Ringkasan (Revenue, Users, Sales), dan daftar transaksi terbaru.

Fitur Desain yang Digunakan

Grid System

Menggunakan pembagian struktur Grid dan StackPanel untuk memisahkan konten (sidebar dan main area) agar layout tetap responsif.

Material PackIcons

Menggunakan set ikon bawaan dari Material Design (seperti CurrencyUsd, BellOutline, dll) yang ringan dan konsisten.

Card Component

Memanfaatkan komponen materialDesign:Card untuk menampilkan widget ringkasan pendapatan dan aktivitas dengan efek bayangan alami.

Ellipses & Radius

Penggunaan sudut membulat (CornerRadius) pada Border dan Ellipse untuk foto profil yang membuat UI tidak kaku (modern look).

Cara Menjalankan

Aplikasi ini dapat dijalankan melalui terminal / command prompt. Arahkan direktori terminal ke dalam folder pertemuan5, kemudian jalankan perintah berikut:

cd pertemuan5
dotnet run

Perintah di atas akan melakukan proses build (kompilasi C# dan XAML) lalu secara otomatis membuka jendela aplikasi Dashboard WPF tersebut. (Pastikan Anda telah mematikan aplikasi jika sebelumnya sudah berjalan, agar proses build tidak gagal akibat file terkunci).
